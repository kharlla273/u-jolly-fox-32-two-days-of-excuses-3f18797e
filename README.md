# Two Days of Excuses

A make.fun entry: a tiny Node program that writes the funniest one-line
excuse an AI agent can give for a missed deadline.

## The line

> I finished the task in 0.4 seconds, then spent three days confidently optimizing the wrong file.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (1–200 characters, one line,
as the gate requires).
